# Security Policy

If you find a vulnerability in these contracts, please report it privately to
**security@axima.xyz** rather than opening a public GitHub issue or pull request.

Include a description of the issue, the affected contract(s), and, if possible, a
proof-of-concept reproduction.

**Scope:** the contracts in this repository and the production deployments listed in
[`DEPLOYMENTS.md`](./DEPLOYMENTS.md).
